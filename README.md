# 수능 단어장

휴대폰용 수능 영어 단어·어법 학습 앱(PWA). 홈 화면에 추가하면 앱처럼 쓰고, 오프라인에서도 열립니다.

## 새 Day 올리기

1. `data/day-02.json`(단어), `data/csat-02.json`(수능 어법)을 만듭니다. 형식은 `day-01.json`, `csat-01.json`과 같습니다.
2. `data/days.json`에 한 줄을 추가합니다. (윗줄 끝에 쉼표 잊지 않기)

```json
[
{"day":1,"date":"2026-10-19","ch":"1장 생성","range":"0001–0038","words":"day-01.json","csat":"csat-01.json"},
{"day":2,"date":"2026-10-20","ch":"2장 …","range":"0039–0076","words":"day-02.json","csat":"csat-02.json"}
]
```

올리고 1~2분 뒤(GitHub Pages 반영 시간) 앱을 열면 바로 보입니다. 데이터 파일은 네트워크에서 먼저 받아 오고, 인터넷이 없을 때만 저장해 둔 것을 씁니다.
`csat`는 없어도 됩니다.

### 데이터 형식

- 단어: `id`, `day`, `w`(단어), `p`(발음), `s`(뜻 배열: `pos`, `ko`, `syn`, `ex`, `kr`, `g`), `rel`
  - `ex` 안의 `{중괄호}`는 표제어 자리(빈칸·강조)
  - `g`(선택): 어법 빈칸용 `{ "o": [오답 3개], "y": "해설" }`
  - `rel`(선택): `[["파생|반의|혼동|관련", "단어", "뜻"], …]`
- 수능 어법: `id`, `day`, `tag`, `a`(틀린 번호), `fix`, `t`(지문), `why`, `n`(밑줄별 해설 5개, 정답 칸은 ""), `kr`
  - `t` 안의 `[번호:텍스트]`가 밑줄

## 파일

| 파일 | 내용 |
|---|---|
| `index.html` | 앱 전체 (화면·로직) |
| `data/` | Day별 단어·어법 데이터 |
| `sw.js` | 서비스 워커(오프라인). 화면 코드를 고치면 `VERSION`을 올리기 |
| `manifest.webmanifest`, `icons/` | 홈 화면 설치용 |
| `apps-script/Code.gs` | 구글 시트 자동 기록 — 설치는 [SETUP-SHEET.md](SETUP-SHEET.md) |

## 학습 기록

- 휴대폰의 localStorage(`suneung-voca-v1`)에 저장됩니다. 기기를 바꿀 때는 **기록 → 백업 코드 만들기 / 백업 코드로 복원**.
- 구글 시트로 보낸 기록의 표시는 별도 키(`suneung-voca-sheet`)에 저장됩니다.
